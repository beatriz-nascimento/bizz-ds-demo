Integration

Web components work in Angular with CUSTOM_ELEMENTS_SCHEMA on the component/module. Attribute binding uses [attr]="value" and custom events use lit standard (bizz-click)="handler($event)" syntax.

Button <bizz-button>

Angular binds to custom events with standard (bizz-click)="handler($event)". Boolean attributes use Angular's [attr.disabled]="value || null" pattern to omit the attribute entirely when false.

{{ buttonLabel() }} @if (buttonLastEvent()) { {{ buttonLastEvent() }} }

Tag <bizz-tag>

Handle it with (bizz-dismissed)="handler()".

@if (tagDismissed()) {
Tag dismissed!
} @else { {{ tagLabel() }} }

Input <bizz-input>

Listen to bizz-input for value changes and bizz-blur for blur events. Access the value via ($event as CustomEvent).detail.

@if (inputValue()) {

Current value: {{ inputValue() }}

}

Card <bizz-card>

Named slots are declared in HTML as slot="card-header". Angular's template syntax works the same as plain HTML here.
